## What it does

Data Quality Watchdog continuously profiles your tables and streams, learning normal patterns and alerting when data breaks — before bad data reaches dashboards, models, or customers.

## Key features

- **Schema drift detection** — new/dropped columns, type changes, and constraint breaks flagged instantly.
- **Freshness & volume monitors** — late or under-sized loads caught per table.
- **Distribution anomalies** — null spikes, outliers, and cardinality shifts detected with ML baselines.
- **Lineage-aware blast radius** — see which dashboards and models each issue impacts.
- **Alert routing** — Slack/email alerts to the dataset owner, not everyone.

## Who it's for

Data engineering and analytics teams running warehouses (Snowflake, BigQuery, Databricks, Postgres) who can't afford silent data breakage.
